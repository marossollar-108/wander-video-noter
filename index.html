Čo robí Video Noter?

Wander Video Noter je open source nástroj, ktorý z videovej prednášky alebo prezentácie vygeneruje prehľadnú HTML stránku. Stránka obsahuje sumarizáciu obsahu aj s extrahovanými obrázkami — takže aj keď si video iba počúvaš, nič ti neunikne. Je to open source, ale potrebuješ svoj API kľúč na nejaký LLM model.

// funkcie

Jedna appka. Všetky poznámky.

01

Video → HTML

Nahráš video alebo odkaz a dostaneš prehľadnú HTML stránku so sumarizáciou a obrázkami. Jednoducho a rýchlo.

02

Extrakcia obrázkov

Appka automaticky extrahuje kľúčové obrázky z videa, aby si nemusel/a video znova prezerať kvôli grafom a diagramom.

03

LLM Sumarizácia

Obsah videa je spracovaný pomocou LLM modelu, ktorý vytvorí prehľadné a zrozumiteľné poznámky z celej prednášky.

04

Vlastný API kľúč

Používaš vlastný API kľúč na LLM model — máš plnú kontrolu nad nákladmi aj nad tým, aký model použiješ.

05

Open Source

Celý kód je otvorený na GitHube. Použi ho, uprav, vylepši — je to tvoje. Žiadne skryté poplatky.

06

Vibe Coded

Postavené z frustrácie a lásky k jednoduchosti. Celá appka vznikla pomocou AI a vibe codingu — dôkaz, že myslieť stačí.
